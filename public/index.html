    Gemma reads. Code counts.

    1. Gemma reads each row

    "Rnd 5: *K4, k2tog; rep from * around. 40 (45, 50, 55) sts." becomes a list: knit 4, knit 2 together, repeat to the end, and the count the pattern promises for each size. Gemma never does the math and never edits your words.

    2. Code does the stitch math

    A stitch table says what each stitch uses and makes: k2tog uses 2 and makes 1, yo makes 1, inc uses 1 and makes 2. The checker carries the live count from row to row, for every size, and checks that every repeat fits.

    3. You get a tech editor's note

    When a count is off, it looks at the next rows to tell a typo from a wrong instruction: "Every later round agrees with 66, so 68 looks like a typo." Lines it can't read are marked "not checked", never guessed.

    Why not just ask a chatbot? We measured it. On 8 test patterns plus 24 copies with one error each, Gemma 4 acting as the editor caught 18 of the 24 errors and raised 17 false alarms on the patterns with nothing wrong. Stitch Math, with Gemma only reading, caught 22 and raised 1 (the full report). Reading is a language job. Counting isn't.

    Cheaper than an hour of tech editing

    Independent tech editors charge around £30 an hour and a pattern takes 30 minutes to 7 hours (one editor's rate card). One designer puts tech editing at about £50 a pattern, on a pattern that sells for about £3.75 (Woolly Wormhead). Stitch Math doesn't replace your editor. It catches the counting slips first, so the hours you pay for go on everything else.

    Your unreleased pattern stays yours

    The checker is open source and the model is open-weight, so you can run the whole thing on your own laptop. The pattern never leaves it.

    ollama pull gemma4:e4b-it-q4_K_M
git clone https://github.com/Hotragn/stitch-math && cd stitch-math
GEMMA_LOCAL=1 npm start

    What it can't check yet

    • Charts, and rows written as "work in pattern as established"
    • "At the same time" shaping, and short rows
    • Whether the finished piece fits or looks right: that's what test knitters and your editor are for

    Built for the DEV Hacktoberfest Open-Source AI Challenge. Runs on a free server that sleeps, so the first check after a quiet spell can take up to a minute.
