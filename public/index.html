    New here? What this checks, in plain words

    A pattern is a promise

    Most rows end with a number, like (18) or 56 sts. That's how many stitches you should have when the row is done. If the instructions don't really make that many, every knitter who follows them ends up stuck, unpicking, and wondering if it's their fault.

    Every stitch has a cost

    Some stitches add, some take away. inc turns 1 stitch into 2. k2tog turns 2 into 1. yo adds 1 from nothing. Add them up across a row and you know exactly how many stitches it makes. Stitch Math does that adding up for every row and every size.

    Sizes multiply the work

    "Cast on 64 (72, 80, 88)" is four patterns in one. A slip in one size is easy to miss by hand. Stitch Math checks each size on its own, and it tells you which size is off.

    Gemma reads. Code counts.

    1. Gemma reads each row

    "*K4, k2tog; rep from * around. 40 (45, 50, 55) sts." becomes a list: knit 4, knit 2 together, repeat to the end, and the count promised for each size. Gemma never does the math and never edits your words.

    2. Code does the stitch math

    A stitch table says what each stitch uses and makes. The checker carries the count from row to row, for every size, and checks that every repeat fits.

    3. You get an editor's note

    It reads ahead to tell a typo from a wrong instruction: "Every later round agrees with 66, so 68 looks like a typo." Lines it can't read are marked "not checked", never guessed.

    Why not just ask a chatbot? We measured it. On 8 test patterns plus 24 copies with one error each, Gemma 4 acting as the editor caught 18 of the 24 errors and raised 17 false alarms on patterns with nothing wrong. With Gemma only reading, Stitch Math caught 22 and raised 1 (the full report). Reading is a language job. Counting isn't.

    Questions

    Do I need to format my pattern a special way?

    No. Paste it the way you wrote it, one row or round per line. Sizes in brackets like "64 (72, 80)" are fine. Materials and notes are skipped.

    Does it replace my tech editor?

    No. It only checks counts. Your editor also checks wording, charts, schematics and fit, and test knitters check how it actually knits up.

    What does "not checked" mean?

    That line didn't have exact numbers, or was written in a way it couldn't read, like a chart or "work in pattern as established". It never guesses, so those lines are left for you.

    Is my unreleased pattern safe?

    Nothing is stored. To keep it on your own computer entirely, run the open-source version with an open model, below.

    Your unreleased pattern stays yours

    The checker is open source and the model is open-weight, so you can run the whole thing on your own laptop. The pattern never leaves it.

    ollama pull gemma4:e4b-it-q4_K_M
git clone https://github.com/Hotragn/stitch-math && cd stitch-math
GEMMA_LOCAL=1 npm start

    What it can't check yet

    • Charts, and rows written as "work in pattern as established"
    • "At the same time" shaping, and short rows
    • Patterns that write each size (or group of sizes) as its own section
    • Whether the finished piece fits or looks right: that's what test knitters and your editor are for
